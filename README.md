# Homebrew tap for soloagent

[soloagent](https://soloagent.dev) is an open-source, self-hosted control plane for durable AI agents that answer in Slack, Discord, Telegram, webhooks, the web, and your terminal.

## Install

```bash
brew install nearbycoder/soloagent/soloagent
```

Or tap first, then install by name:

```bash
brew tap nearbycoder/soloagent
brew install soloagent
```

Then:

```bash
soloagent            # terminal UI with a private local server
soloagent serve      # web dashboard on http://localhost:7420
soloagent token      # print the dashboard login token
```

Upgrade with `brew upgrade soloagent`. The formula depends on Homebrew's `node` and installs the npm package from the [GitHub release](https://github.com/nearbycoder/soloagent.dev/releases) tarball.

## How this tap is updated

`Formula/soloagent.rb` is generated by [`scripts/update-homebrew.mjs`](https://github.com/nearbycoder/soloagent.dev/blob/main/scripts/update-homebrew.mjs) in the main repo. When a `v*` tag is released, the release workflow rewrites the formula's `url` and `sha256` and pushes it here (when the `HOMEBREW_TAP_TOKEN` secret is set). To update it by hand:

```bash
node scripts/update-homebrew.mjs ../homebrew-soloagent/Formula/soloagent.rb --version 0.1.1
```

The workflow in this repo runs `brew audit`, installs the formula from source, and runs its test on macOS and Linux.

Issues with soloagent itself belong in [nearbycoder/soloagent.dev](https://github.com/nearbycoder/soloagent.dev/issues).
